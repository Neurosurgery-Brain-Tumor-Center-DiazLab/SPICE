# SPICE v0.2.0

SPICE v0.2.0 has been tagged and [released on GitHub](https://github.com/Neurosurgery-Brain-Tumor-Center-DiazLab/SPICE/releases/tag/v0.2.0).
Its version-specific Zenodo archival DOI is [10.5281/zenodo.22821665](https://doi.org/10.5281/zenodo.22821665).

SPICE 0.2.0 is the first hardened SPICE release, providing an installable
`spice-lineage` Python distribution and the seven-command `spice` CLI for
Single-cell Plasticity Inference and Clonal Evolution.

- **Inputs and lineage inference:** standardized `matrix.tsv`, `variants.tsv`
  and `cells.tsv` bundles, optional Monopogen import, filtering, IQ-TREE lineage
  inference and standalone `spice clones` for existing supported trees.
- **Ancestry and plasticity:** modern BayesTraits MCMC diagnostics, QC and fresh
  retries; ordered-state plasticity, tip-state permutation testing and
  clone-family Benjamini–Hochberg FDR summaries.
- **Reproducibility:** runtime settings, tool/package versions, executable and
  source hashes, completion status and retained QC evidence.
- **Distribution and Galaxy:** validated local Conda/OCI packaging, five native
  Galaxy wrappers (`0.2.0+galaxy0`) and a clone-collection workflow pinned to
  IUC IQ-TREE `2.4.0+galaxy2`.
- **Independent cold start:** fresh non-editable installation, all commands,
  filtering, three expected clones, standalone clone equivalence, ancestry QC,
  9/9 requested permutations, summary and provenance passed; a fresh locked
  real-tool integration passed with zero skips.

## Installation and validation scope

Use the [validated Conda/micromamba installation](../../wiki/Installation.md#recommended-installation-condamicromamba)
and [end-to-end synthetic exercise](../../wiki/Tutorial.md#end-to-end-synthetic-cli-exercise).
Validation targets **Linux x86_64**, with **IQ-TREE 2.4.0** and
**BayesTraits V4.1.3**. BayesTraits remains externally supplied and is not
redistributed. Synthetic validation establishes software operation, not
biological accuracy or native Windows/macOS support.

## Compatibility

Posterior columns use state codes; join `.state_mapping.tsv` for original
labels. Older ancestry results without QC-policy metadata require a new
ancestry run before use with the updated plasticity command. BayesTraits V4
receives a temporary full-precision NEXUS copy without internal support labels;
original trees, supports and scientific identities are preserved.
