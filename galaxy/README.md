# SPICE Galaxy tools

Five native tools wrap installed `spice-lineage=0.2.0`: Filter, Clones,
Ancestry, Plasticity and Summarize. Wrapper version is `0.2.0+galaxy0`,
profile `25.0`. SPICE **0.2.0** is released
([Zenodo DOI](https://doi.org/10.5281/zenodo.22821665)).

See [the Galaxy guide](../docs/galaxy.md) for administration, local Planemo
validation and the publication boundary, and [the tutorial draft](training/tutorial.md)
for synthetic data and collection mapping. Tool Shed and GTN publication
are still pending. The intended Tool Shed repository is `diazlab/spice_lineage`.
[Bioconda PR #69381](https://github.com/bioconda/bioconda-recipes/pull/69381) has merged.
Public `spice-lineage=0.2.0` build `pyhdfd78af_0` passed fresh Linux installation
and release-payload checks on 2026-10-19; see the [validation record](../docs/public-distribution-validation-2026-10-19.md).
Public deployment also requires administrator provision of external
BayesTraits V4.1.3, which is not redistributed.

- `tools/`: shared macros, five XML wrappers, orchestration-only JSON adapter,
  synthetic tests, `.shed.yml` publication metadata and a [Tool Shed README](tools/README.rst).
- `workflows/spice_lineage_analysis.gxwf.yml`: editable Format 2 workflow source.
- `workflows/spice_lineage_analysis.ga`: native workflow generated by gxformat2.
- `workflows/*-job.yml` and `*-tests.yml`: explicit reduced integration settings
  and assertions; these are not recommended scientific analysis settings.
- `workflows/tools.yml`: pinned IUC IQ-TREE 2.4.0 Tool Shed dependency.

Do not substitute the latest IUC IQ-TREE revision: it uses IQ-TREE 3, outside
SPICE's validated inference contract. This workflow pins owner `iuc`, repository
`iqtree`, changeset `e727e82945af`, tool `2.4.0+galaxy2`.
