# Local OCI staging image

The Containerfile consumes the minimal build context generated by
scripts/check_distribution.py: the locally built Conda artifact, its exact
solved runtime lock and the Containerfile. It never installs SPICE from pip,
copies a checkout, or downloads BayesTraits.

The Linux/amd64 mambaorg/micromamba:2.3.2 base is pinned to platform manifest
sha256:955819619f303e2aa1dc1ba89beefe7f326a378b3d0782a4a0d28b1cf11b68b6.
Its parent multi-platform index is
sha256:ce2026639d612fbe837a35ca9d513292a8d776a24a5e6c82cccf9dddf45ad3d2.
The runtime stage copies only /opt/conda from the install stage. Download caches,
the local channel and the input lock are not copied into runtime layers.

ENTRYPOINT is empty. spice and Rscript are directly on PATH, including with an
arbitrary host UID/GID. The default non-root command displays spice help.

Build and run all checks as documented in [distribution.md](../../docs/distribution.md).
The generated container-context directory can also be built directly:

~~~bash
docker build --platform linux/amd64 \
  --build-arg PACKAGE_SHA256="$(sha256sum /tmp/spice-distribution/channel/noarch/spice-lineage-*.conda | cut -d' ' -f1)" \
  -t spice-lineage:phase5-local /tmp/spice-distribution/container-context
docker run --rm spice-lineage:phase5-local spice --version
~~~

The tag is local and is never pushed. For a separately acquired, licensed
Linux BayesTraits V4.1.3 executable, mount only that executable read-only:

~~~bash
docker run --rm --user "$(id -u):$(id -g)" \
  --mount "type=bind,src=/absolute/path/BayesTraitsV4,dst=/external/BayesTraitsV4,readonly" \
  --mount "type=bind,src=/absolute/path/inputs,dst=/inputs,readonly" \
  --mount "type=bind,src=/absolute/path/results,dst=/results" \
  -e BAYESTRAITS_BIN=/external/BayesTraitsV4 -e HOME=/tmp \
  spice-lineage:phase5-local spice ancestry \
  /inputs/tree.nwk /inputs/states.tsv /results sample
~~~

The host results directory must already exist and be writable by the invoking
UID. This runtime-supply pattern does not redistribute BayesTraits in the image.
Phase 5's distribution tests verify the missing-tool error, not mounted
BayesTraits inference. The existing Phase 3 integration suite verifies V4.1.3.
